# Zotero Add-on

This directory will contain the UniZero Zotero add-on.

It owns Zotero lifecycle, UI, feature modules, scholarly providers, Zotero adapters,
preferences, localization, and the typed client for the local paper runtime.

No application code has been migrated yet. Zoference is the initial source for the
build and lifecycle foundation; ZoMiner's Zotero-facing capabilities will be ported in
a later phase.
